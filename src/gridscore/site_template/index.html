GB Grid Forecast Scoreboard

Can a transparent probabilistic model beat NESO's own carbon-intensity forecast — and when does it fail? Every forecast below was committed to Git before its outcome existed, then scored against real data.

Verdict: challengers vs NESO

Δ = mean pinball loss of the challenger minus NESO's, paired on identical targets. Negative = challenger better. Bars are 95% moving-block-bootstrap intervals over days.

Read both views. NESO publishes a point forecast with no intervals, so any model that outputs calibrated bands has a built-in edge on pinball loss; point accuracy is the like-for-like test of the central forecast. Each view is its own pre-registered family: 3 challengers × 3 horizon buckets, Holm-adjusted. A verdict needs ≥ scored days, a CI excluding 0 and an adjusted p < 0.05. The 0–48 h row is descriptive.

Leaderboard

All models scored on exactly the same targets (common support). NESO issues a point forecast only, so its interval columns are empty by design.

The forecasts themselves

Shaded bands = 50% and 90% predictive intervals. Choose a batch and the models to display.

Calibration — do the intervals mean what they say?

If a model says "90%", about 90% of outcomes should land inside. Points on the diagonal are calibrated; a flat line at 0.5 is what a point forecast looks like.

Over time

Daily paired Δ pinball vs NESO (dots) and 7-day rolling mean (line). Below zero = the challenger is ahead that day.

When does it fail?

Stratified by information known at issue time (local time, day type, NESO's forecast level) — never by the realised outcome, which would bias calibration. Exploratory: no multiplicity adjustment.
